# PM Capture Lab

ディーゼル車向けフィルターレスPM回収システムの挙動を可視化する、ブラウザ完結型の2D簡略物理シミュレーターです。

## 起動

GitHub Pagesで公開する場合は、リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定してください。`main` への push 後、`.github/workflows/pages.yml` が自動デプロイします。

## 機能

- 粒子の流動・沈降・凝集・荷電・サイクロン分離の模式的な可視化
- 音響凝集、静電凝集、熱泳動、サイクロン、DPFのON/OFFと配置スロット
- 排気流速、PM濃度、排気温度などの条件変更
- 回収率、背圧、排出PM量、タンク蓄積量のライブ表示
- 重力のみとの比較グラフ、3種類のプリセット

## 注意

本アプリは高校物理ゼミ等での概念理解・構想比較を目的とする簡略モデルです。実機設計、性能保証、法規適合性の判断には使用できません。Pa・mg等の表示はモデル係数による参考値であり、実測値ではありません。
